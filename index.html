仕入れ台帳の自動連携

Googleスプレッドシートの「仕入れ台帳」に行を足すと、数分後に自動で「保管」の商品として入るようにします。最初に1回だけ、台帳にプログラムを貼る作業が要ります。

いつ以降の仕入れを入れるか
  1. パソコンで script.google.com を開き、「新しいプロジェクト」を押す（台帳を見られるGoogleアカウントで。台帳の「拡張機能」→「Apps Script」からでも同じです）。
  2. 最初から書いてある文字を全部消して、コピーしたプログラムを貼り、フロッピーの絵（保存）を押す。
  3. 上の「実行する関数」で setup を選んで「実行」を押す。
  4. 「承認が必要です」と出たら、自分のGoogleアカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」を押す。自分で貼ったプログラムなので、この表示が出ます。
  5. これで完了。5分おきに台帳を見て、新しい行だけTick Takに入れます。
  6. 「The OAuth client is not fully created yet」と出たら、作ったばかりで準備中です。10分ほどおいて、もう一度 setup を実行してください。Googleの保存容量がいっぱいのアカウントでは作れないことがあります。

このプログラムには連携用の合言葉が入っています。ほかの人に渡さないでください。

仕入れ台帳を読み込む

Googleスプレッドシートの「仕入れ台帳」で、入れたい行（商品名〜支払日）を選んでコピーし、下に貼って「読み込む」。1行が「保管」の商品（仕入値・仕入日・仕入先つき）として入ります。前に読み込んだ行は飛ばすので、月のタブを丸ごと貼り直しても二重になりません。出品者の名前と住所は取り込みません。

売れた商品を型番につなぐ

型番がまだ付いていない商品を、タイトルに型番（Reference Number）が含まれるかで探してつなぎます。すでに型番が付いている商品は変えません。つなぐと、登録画面でその型の販売実績が出ます。

説明文のひな形

出品の説明文は、決まった新しいデザイン（白地・黒・金、状態の目盛りつき）で自動で作ります。下のひな形は今は使っていません。{title} {condition} {condition_note} {appearance} {accessories} {size} {specs} の場所に商品の中身が入ります。
